# アウトサイダー主張傾向アップデート

アウトサイダーの主張行動を「早出し型」「潜伏型」「中立」に分け、アウトサイダー人数を変える役職の推理に使うようにしました。

## 早出し型

- 執事
- 隠者
- 酔っ払い
- 修理屋

## 潜伏型

- 聖人
- 狂人
- 突然変異者

## 中立

- 用心棒
- 月の子
- 恋人
- 床屋
- 不器用者

## 人数変更役職との連動

- 男爵 / ファン・グー: 追加アウトサイダー枠によって早出し型が必ず必要になるのに、その主張がなければ候補の重みを大きく下げます。
- ヴィゴモルティス: -1 アウトサイダーが、通常なら必要な早出し型を消す場合に限って弱い支持根拠にします。
- 潜伏型・中立型が未主張であることは、「人数が少ない」証拠としては扱いません。

## 不完全な主張記録

テーブル全体の役職主張がまだ少ない段階では、「早出し型がいない」ことを強い証拠にしません。約35%以下の主張収集率では補正を0にし、約85%で最大強度になります。

## 再現テスト

8人TB、通常アウトサイダー1人、聖人だけがアウトサイダー主張、その他の全員に具体的な役職主張がある条件で、12,000回の固定シード探索の男爵割合は約0.016%でした。
