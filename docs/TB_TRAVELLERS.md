# トラブル・ブルーイング旅人対応

## 対象

この更新では、トラブル・ブルーイングの5人の旅人を通常役職とは別レイヤーで扱います。

- 官僚
- 物乞い
- ガンスリンガー
- スケープゴート
- 泥棒

旅人は通常の `RoleId`・スクリプト役職一覧・5〜15人のセットアップ人数には入りません。旅人の追加と管理は指名/投票画面から行い、参加中の旅人だけが盤面中央に表示されます。

## 投票

指名記録は「挙手した人」と「実際の合計票」を別々に保存します。これにより、後から旅人が死亡・追放しても過去の集計は変わりません。

- 官僚: 前夜に選んだプレイヤーの翌日の票を3票として扱います。
- 泥棒: 前夜に選んだプレイヤーの翌日の票をマイナス票として扱います。
- 官僚と泥棒が同じプレイヤーを選んだ場合は -3 票として扱います。
- 物乞い: 生存中は投票トークンがないと投票できません。死亡者から受け取ったトークンはその死亡者の通常の死者票を消費します。
- ガンスリンガー: その日の最初の投票で挙手したプレイヤーから射殺対象を記録できます。
- スケープゴート: 身代わり処刑を記録でき、その対象と同陣営であることを善悪推定に利用します。

## 盤面中央

参加中の旅人が1人以上いる場合だけ、左右の通常プレイヤー列の中央に旅人カードを表示します。カードには公開役職、名前、生死、現在の悪推定を表示し、タップすると旅人専用管理画面を開きます。

## 善悪ボタン

上部の `推理` の隣に `善悪` ボタンを追加しました。

- 通常プレイヤー: 既存の候補ワールドの重み付き悪陣営比率を表示します。
- 旅人: 役職行動・投票・スケープゴートの同陣営情報などから別の行動ベース推定を表示します。
- 旅人の数値は候補ワールド内の機械的確率ではないため、画面上でも明示的に区別します。
- 旅人の陣営を手入力で確定した場合、その値を優先します。

## 保存互換性

既存セーブでは `travellers` / `travellerActionLog` が存在しなくても正常に読み込めます。新しい旅人情報は既存スキーマの任意フィールドとして保存します。

## 現時点の境界

- この第1段階では旅人を通常の役職候補ワールドへ直接混ぜません。
- 旅人は投票参加者として扱いますが、通常プレイヤー席を占有しません。
- 旅人の追加/管理はメインメニューには置かず、指名/投票画面内に置きます。
- 旅人の追放は旅人管理画面で状態として記録します。追放投票そのものを通常の処刑投票としては扱いません。
- Chef / Oracle など「旅人の実陣営まで参照する情報役職」との完全な候補ワールド分岐は今後の旅人推理拡張で扱います。今回の善悪画面では、この未確定陣営を通常プレイヤーの確率へ混ぜていません。

## 官僚・泥棒の日次対象

官僚と泥棒の対象は各夜ごとに独立して記録されます。`N1` の対象は `D1` の投票だけに影響し、`D2` には引き継がれません。次の夜へ進むと入力中の対象もクリアされます。

通常プレイヤーをタップして「能力発動」を開くと、スクリプト上の処刑人に加え、現在活動中かつ生存中の官僚・泥棒が選択肢に出ます。

- 処刑人: タップしたプレイヤーが能力使用者。
- 官僚 / 泥棒: タップしたプレイヤーが能力の対象（受け手）。能力使用者は中央の旅人。

同じ夜に対象を選び直すと、その旅人のその夜の対象を上書きします。

## 旅人の追放

メインメニューに `旅人を追放` を追加しました。参加中の旅人を選ぶと確認後に追放されます。

- 追放は通常の死亡とは別状態です。
- 追放された旅人は `active=false` になり、能力は即座に停止します。
- 盤面中央の旅人表示から外れます。
- 投票画面には追放済み旅人として残り、死者票を1票だけ使用できます。
- 死者票を使用した後は `追放・死者票使用済み` と表示され、以後投票できません。
- 追放時点は `exiledWhen` として保存されます。
- 旅人パネル内の追放ボタンも同じ処理を使用します。
