# 実験的旅人: カックルジャック / ノーム / ギャングスター

## 追加された旅人

- **カックルジャック**
  - 毎日1人を「今夜変えられない人」として記録。
  - N2以降、語り手が実際に役職変更した対象と変更後役職を記録。
  - 前日にカックルジャックが選んだ人を同じ夜の変更対象にする入力は拒否。
  - 通常席のプレイヤーへの役職変更は候補世界の現在役職にも反映し、陣営は維持。
  - 旅人を通常役職へ変える特殊ケースはイベントとしては保存するが、通常席の候補世界には投入しない。

- **ノーム**
  - 公開された「同陣営の友人」を保存。
  - その友人への指名記録から、指名者を選んで死亡結果を保存可能。
  - 実際に死亡した場合は死亡原因を **ノーム** として独立保存。
  - 公開された友人の陣営情報を善悪推定に反映。
  - 何度でも使用できるため、指名ごとに別イベントとして保存。

- **ギャングスター**
  - 1日1回。
  - 「同意した生存隣人」と「死亡させるもう一方の生存隣人」を手動指定。
  - 旅人は中央表示で固定席を持たないため、隣人判定そのものはユーザー入力とする。
  - 実際に死亡した場合は死亡原因を **ギャングスター** として独立保存。
  - 保護などで死亡しなかった場合も能力使用済み記録は残る。

## 特殊死亡タグ

ノームとギャングスターは `SPECIAL_DEATH_CAUSE` タグを持つ。
通常プレイヤーの死亡イベントでは `reason: gnome` / `reason: gangster` を使い、汎用の「能力」死亡と区別する。

## 旅人追加メニュー

「旅人を追加・管理」の役職選択を **全旅人** 1リストに変更。
TB/BMR/S&V/実験的の所属にかかわらず、現在登録されている18旅人を常に選択できる。
旅人は引き続き通常RoleId・スクリプト人数・セットアップ人数には入らない。
