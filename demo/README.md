# Fictional demonstration game

Import `trouble-brewing-example.json` from the home screen. Export your current game first. Import replaces the active game after confirmation and clears its undo stack.

This is a constructed 9-player example, not a real game. The example is compatible with this starting world:

| Seat | Actual role in the constructed example |
| --- | --- |
| self | Empath |
| 1L | Washerwoman |
| 2L | Fortune Teller |
| 3L | Monk |
| 4L | Virgin |
| 4R | Recluse |
| 3R | Drunk, believing Undertaker |
| 2R | Poisoner, bluffing Fortune Teller |
| 1R | Imp, bluffing Soldier |

The app is **not told this hidden table**. Only the visible/claimed events are imported. It is expected to retain alternatives rather than magically recover the constructed answer.

The record includes a Virgin nomination/execution, later deaths of privately claimed Monk and FT, a duplicate FT claim, a reported UT Imp result, your own Empath results, and a conversation whose topic is unknown. A deliberately outdated personal read on the publicly demonstrated Virgin produces yellow independently of sampling.

Search results and percent shares are generated normally. No warnings or probabilities are hardcoded into the example.
